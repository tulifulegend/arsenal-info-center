说明

这是一个公开网页，不用登录。收藏只存在你这台设备的浏览器里，换浏览器或清掉网站数据就会消失。

数据从哪来

  • 新闻：Arseblog 和 卫报足球 · 阿森纳 的订阅源。只用标题、短摘要和链接，供个人、非商业查看。
  • 播客：Arsecast。只保留最近几期正集、Extra 和女足节目的标题、简介和官方链接。
  • 赛程：API-Football 免费接口里的男足一线队。女足赛程不在这一版。维护者需要在 GitHub 里配置密钥后，赛程才会出现。密钥不会写在这个网页里。

如果某次更新失败，页面继续显示上次成功拿到的内容，并写明仍在显示缓存。失败的结果不会覆盖已经成功的数据。

如果免费接口没有给全本赛季或杯赛，页面会直接说覆盖不完整，不会自己补场次，也不会改去付费套餐。
